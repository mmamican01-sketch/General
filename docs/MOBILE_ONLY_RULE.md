# قاعدة: التعديلات للجوال فقط

**من الآن فصاعداً:** جميع التحسينات والتعديلات تطبق على **الهاتف فقط**. الديسكتوب مُجمّد (frozen).

## كيفية التطبيق

- استخدام `md:` أو `sm:` لاستثناء الديسكتوب
- التعديل يطبق على الافتراضي (mobile) فقط
- الديسكتوب يستعيد قيمه الأصلية عبر `md:` أو `lg:`

## أمثلة

```html
<!-- ✅ صحيح: التعديل للجوال فقط -->
class="-ml-24 md:-ml-16 lg:-ml-24"
class="text-sm md:text-base"
class="px-4 md:px-8"
class="max-h-[120px] md:max-h-[80px]"

<!-- ❌ خطأ: يغيّر الديسكتوب -->
class="-ml-24"
class="text-sm"
```

## Breakpoints

- **default** (< 768px): جوال / تابلت صغير
- **md** (768px+): ديسكتوب — لا نغيّره
- **lg** (1024px+): ديسكتوب كبير — لا نغيّره
